## 1. Теоретическая база

### **Цель работы:**
Научиться работать с предобученными моделями и на основе предобученных эмбеддингов строить новые модели.

---
### **Трансформеры и их значение**

**Трансформеры** — это архитектура нейронных сетей, которая стала основой для современных моделей обработки естественного языка (NLP). Она была предложена в статье **"Attention is All You Need"** в 2017 году и позволяет моделям эффективно обрабатывать текстовые последовательности без использования рекуррентных слоев.

#### **Ключевые компоненты трансформеров:**

1. **Токенизация:**
   - Исходный текст разбивается на токены — минимальные единицы текста (например, слова или части слов).
   - Каждому токену присваивается числовое представление.

2. **Эмбеддинги:**
   - Каждый токен кодируется в виде эмбеддинга — вектора фиксированной длины, который отражает его смысловое значение.
   - Модели могут обучаться на этих эмбеддингах, чтобы лучше понимать контекст.

3. **Позиционные эмбеддинги:**
   - Поскольку трансформеры не обрабатывают данные последовательно, позиционные эмбеддинги добавляются для учета порядка слов в предложении.

4. **Self-Attention:**
   - Для каждого токена вычисляется его важность относительно всех остальных токенов в предложении.
   - Это позволяет модели учитывать контекст всего предложения при обработке каждого отдельного слова.

5. **Многоголовое внимание (Multi-Head Attention):**
   - Использование нескольких "голов" внимания помогает модели анализировать разные аспекты текста одновременно.

---
### **BERT и его улучшения**

**BERT (Bidirectional Encoder Representations from Transformers)** — это одна из самых популярных моделей трансформеров, предложенная Google AI в 2018 году. Модель обучается анализировать текст как слева направо, так и справа налево (двунаправленное внимание), что позволяет ей учитывать контекстное значение слов.

#### **Особенности BERT:**

1. **Двунаправленность:**
   - Модель учитывает контекст слов как до, так и после текущего токена, что улучшает понимание смысла текста.

2. **Предобучение:**
   - BERT обучается на больших текстовых корпусах, таких как Wikipedia.
   - Используются две основные задачи:
     - **Masked Language Model (MLM):** Некоторые токены маскируются, и модель обучается предсказывать их.
     - **Next Sentence Prediction (NSP):** Модель предсказывает, является ли второе предложение логическим продолжением первого.

3. **Предобученные модели:**
   - Это модели, уже обученные на больших наборах данных, которые можно использовать для решения различных задач без обучения "с нуля".
   - Пользователь может дообучить модель на своих данных (fine-tuning), чтобы адаптировать её под конкретные задачи.

---
### **RoBERTa**

**RoBERTa (Robustly optimized BERT approach)** — это улучшенная версия BERT, предложенная Facebook AI для оптимизации производительности и устранения ограничений оригинальной модели BERT.

#### **Основные улучшения RoBERTa:**

1. **Отказ от задачи предсказания следующего предложения (NSP):**
   - В BERT использовалась задача NSP для обучения модели предсказывать логическую последовательность предложений.
   - RoBERTa полностью отказалась от этой задачи, что улучшило производительность модели.

2. **Динамическое маскирование:**
   - В BERT маскирование токенов происходило статически до начала обучения.
   - RoBERTa применяет динамическое маскирование, где маскируемые токены меняются на каждой эпохе, что повышает эффективность обучения.

3. **Обучение на больших объемах данных:**
   - RoBERTa обучена на значительно большем объеме текстов, включая наборы данных Common Crawl и BooksCorpus.

4. **Более длинные последовательности:**
   - RoBERTa поддерживает обработку более длинных последовательностей токенов, чем BERT.

5. **Улучшенная производительность:**
   - Благодаря оптимизации гиперпараметров и удалению задачи NSP, RoBERTa показывает лучшие результаты на многих задачах NLP.

6. **Поддержка многозадачного обучения:**
   - Модель RoBERTa эффективно адаптируется к различным задачам без необходимости значительных модификаций архитектуры.

#### **Ключевые отличия от BERT:**

| Особенность      | BERT            | RoBERTa         |
|------------------|-----------------|-----------------|
| NSP (Next Sentence Prediction) | Есть             | Нет             |
| Маскирование     | Статическое     | Динамическое    |
| Объем данных     | Меньше          | Больше          |
| Последовательности| 512 токенов    | Поддержка более длинных последовательностей |
| Гиперпараметры   | Базовые         | Оптимизированные|

## 2. Алгоритм работы разработанной системы

1. **Очистка и подготовка данных:**
   - Приведение текста к нижнему регистру.
   - Удаление пунктуации и чисел.
   - Удаление эмодзи и стоп-слов.
   - Преобразование категорий в числовые метки.

2. **Загрузка и настройка предобученной модели RoBERTa:**
   - Используется модель "roberta-base" из библиотеки Hugging Face Transformers.
   - Выполняется токенизация текстов с паддингом и усечением.

3. **Обучение и предсказание:**
   - Обучение модели выполняется с использованием метода AdamW.
   - Предсказания производятся батчами для эффективной обработки больших объемов данных.

4. **Оценка качества модели:**
   - Используются метрики Precision, Recall и F1 Score для оценки производительности модели.
